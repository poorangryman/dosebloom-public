DOSEBLOOM 1.3.0 — ЗАМЕНА ФАЙЛОВ В СУЩЕСТВУЮЩЕМ ПРОЕКТЕ

Самый безопасный способ обновить существующий проект — не создавать новый проект.

1. Закройте приложение на телефоне. Android Studio можно оставить открытым.
2. В Android Studio слева откройте режим Project (Android тоже подходит).
3. Найдите:
   app > src > main > kotlin > com > dosebloom > app > MainActivity.kt
4. Правой кнопкой по MainActivity.kt -> Open In / Show in Explorer (название пункта зависит от версии Android Studio).
5. В открывшемся Проводнике замените старый MainActivity.kt новым файлом из архива:
   update/app/src/main/kotlin/com/dosebloom/app/MainActivity.kt
6. Аналогично найдите:
   app > build.gradle.kts
   и замените его файлом:
   update/app/build.gradle.kts
7. Вернитесь в Android Studio.
8. Если появится кнопка Sync Now — нажмите её.
9. Выполните Build > Make Project.
10. Если сборка успешна, для APK:
    Build > Generate Signed App Bundle / APK > APK > Next > release > Finish.

ВАЖНО:
- Не заменяйте папку проекта целиком.
- Не удаляйте базу данных приложения на телефоне.
- Не меняйте applicationId: он должен остаться com.dosebloom.app.
- Версия 1.3.0 имеет versionCode 7.
- Для обновления уже установленного APK нужно использовать тот же release-ключ.
- В полном архиве проекта уже сохранены dosebloom-release.jks и keystore.properties.
- Файлы подписи нельзя публиковать в GitHub.
